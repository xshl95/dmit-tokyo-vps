## 「三网直连」先拆开看，不然很容易被词忽悠

三网指的是电信、联通、移动。直连指的是流量不绕第三方中转，这里还分去程和回程两段：去程是国内到日本这一段（影响上传、请求响应），回程是日本回国内这一段（影响下载、网页打开速度）。真正决定日常体感的是**回程**。

对应的线路名字就那么几个：

- 电信：CN2 GIA（AS4809，路由里能看到 59.43 开头的节点段）是顶级；普通的是 163 出口（AS4134）
- 联通：AS9929 / AS10099 精品网算优质；普通的是 AS4837 国际出口
- 移动：CMI / CMIN2（AS58453）属于优化线路

商家宣传里的「三网直连」，可能指三网都走了上面这些优质线路，也可能只是指「能连上，没绕地球一圈」。判断方法很简单：**看它敢不敢写回程走哪条线，敢不敢给测试 IP。**

> 只写「三网直连」四个字、不给回程线路名称和测试 IP 的商品，先按普通国际线路预估，不会吃亏。

## 日本机房为什么比美国贵一大截

东京离中国大陆近，延迟通常在 50–90ms 区间，美西普遍在 150ms 以上，这是物理距离决定的，谁也改不了。而中国方向的优质带宽在东京是稀缺资源，CN2 GIA 的日本段容量尤其紧张，所以价格下不来。

DMIT 自己的产品线也能印证这一点：同样是三网 CN2 GIA 的入门款，香港 HKG.Pro.TINY 月付 39.9 美元起，东京 TYO.Pro.TINY 是 21.9 美元起。日本比香港便宜将近一半，比美西的同类优化机型贵，属于中间档。

## 怎么自己验证一条线路是不是真直连

别只看商家页面上的宣传词，用这几个工具实测：

1. 先 ping 测试 IP。东京 Pro 用 `154.12.190.32`，T1 用 `154.31.112.5`，看延迟和丢包。
2. 用 Looking Glass 从机房侧回测你的本地 IP，能直接看到回程走的是哪条线路。
3. 自己搭好后跑三网回程路由追踪，重点看每一跳是不是落在 CN2（59.43 段）、9929、CMI 这些名字上，还是掉进了 163（AS4134）、AS4837 这类普通出口。
4. 晚高峰（20:00–23:00）再测一遍。优质线路和普通线路的差别，平时看不出来，这个时段最明显。

## 常见问题

**「三网直连」等于 CN2 GIA 吗？**
不等于。三网直连只说三家的流量都走了相对直接的路径，具体走 CN2 GIA、9929、CMI 还是 NTT，差别很大。一定要问到具体线路名。

**Pro 和 T1 能换吗？**
这是个下单纯选的问题。所以建议先月付试用，用下来不合适再调整，比一次年付赌对要稳。

**为什么日本比香港便宜，却比美国贵？**
因为成本结构不一样。日本离大陆近、带宽质量好，但优质回国带宽容量有限；美国机房资源丰富，可日本在延迟上有天然优势，这个优势对国内用户是有溢价的。

**流量跑超了会立刻断网吗？**
看系列。T1 是限速继续跑，不停机；Pro 是直接暂停服务，等新周期开始或升级套餐才恢复。

**适不适合拿来建站？**
日本原生 IP、Pro 的三网 CN2 GIA 回程、1Gbps 端口，做面向国内访问的中小型站点是合适的，第三方测评也提到流媒体和 AI 类服务解锁情况不错。但 Pro 入门款只有 500GB 流量且超额暂停，流量敏感型站点要么选更高的档位，要么考虑 T1。
